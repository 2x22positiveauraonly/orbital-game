# Orbital Dispatcher (Космический симулятор)

## Цель игры
Управлять тремя спутниками на орбите Земли, изменяя их траектории с помощью реактивной тяги, и не допустить столкновения аппаратов.

## Правила и управление
* **ПК**: Стрелки `←`/`→` — поворот, `↑`/`↓` — тяга/торможение. `TAB` — сменить спутник. `R` — рестарт.
* **Телефон**: Экранные кнопки навигации (появляются внизу экрана).
* **Победа/Проигрыш**: Игра бесконечна, но если спутники сталкиваются или падают на Землю/улетают в космос — вы теряете аппарат.

## Как запустить
Игра запускается в любом современном браузере (Chrome, Safari, Firefox, Edge). Просто откройте файл `game.html`.

## Ограничения
Физическая модель упрощена (двумерная, без учета сопротивления атмосферы). Масса спутников не влияет на гравитацию.

## Источники
Вдохновлено играми *Asteroids*. Графика нарисована с помощью HTML5 Canvas.
